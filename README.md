# Ukrainian CEDICT — китайсько-український словник

Відкритий проєкт китайсько-українського словника на основі [CC-CEDICT](https://www.mdbg.net/chinese/dictionary?page=cc-cedict). Тут можна завантажити дані, перевірити їхню структуру та запропонувати виправлення.

**Це машинно перекладена чернетка з частковою перевіркою моделлю. Людської валідації немає.** Відсутність позначки про сумнів не гарантує правильності. Дані не сертифіковані й потребують мовної перевірки перед використанням у навчанні або застосунках.

## Завантаження

- [dictionary.json](dictionary.json) — основний формат: записи, сегменти, джерело й статус перевірки.
- [dictionary.csv](dictionary.csv) — ті самі записи; поля-масиви закодовані як JSON, файл має UTF-8 BOM.
- [progress.json](progress.json) — лічильники, обмеження та SHA-256 основних файлів.
- [source.json](source.json) — версія джерела, атрибуція та його контрольна сума.
- [translation_prompt.txt](translation_prompt.txt) — вихідна інструкція машинного перекладу англійською.

На GitHub використайте **Raw / Download raw file** для окремого файлу або **Code → Download ZIP** для всього репозиторію. CSV варто імпортувати як текст, щоб табличний редактор не перетворив піньїнь чи інші поля.

## Як читати дані

Один запис відповідає поєднанню традиційного написання, спрощеного написання й точного піньїню. Варіанти вимови можуть мати різні записи.

- `traditional`, `simplified`, `pinyin` — незмінені поля CC-CEDICT.
- `english_segments`, `ukrainian_segments` — відповідні масиви сегментів в однаковому порядку. Індекс починається з **0**. Межі сегментів успадковано від розділювача `/` у CC-CEDICT Version 1; вони не завжди означають окремі лінгвістичні значення.
- `id` — перші 16 шістнадцяткових символів SHA-256 від `traditional + TAB + simplified + TAB + pinyin` у UTF-8. Регістр, пробіли, тони й написання `u:` мають значення.
- `raw_source`, `source_line` — початковий запис і номер рядка у зафіксованому джерелі. Записи впорядковані за `source_line`.
- `translation_status: "model_generated"` — машинне походження перекладу.
- `model_reviewed`, `review_status`, `review_rating_before_corrections` — факт та оцінка перевірки моделлю **до** застосованих виправлень; це не остаточний висновок про правильність.
- `correction_count` — кількість уже врахованих виправлених сегментів.
- `has_known_uncertainty`, `uncertainty_flags`, `uncertainty_notes` — відомі застереження; перелік неповний.
- `human_validation` — у цій версії завжди `false`.

Китайське слово та його читання визначають значення; англійські сегменти допомагають його уточнити. Китайські посилання й піньїнь у квадратних дужках мають зберігатися дослівно у відповідному українському сегменті. Мета перекладу — стислі природні українські словникові відповідники зі збереженням стилістичних, граматичних і галузевих уточнень.

Для генерації запитано конфігурацію `gpt-6-luna` з рівнем міркування `xhigh`. Точна ідентичність фактично використаної моделі та витрата токенів недоступні. Окрема модель перевірила лише частину записів.

## Локальна перевірка

Потрібен **Python 3.9 або новіший**. Залежностей і доступу до мережі немає. У корені завантаженого репозиторію виконайте:

```sh
python3 scripts/validate.py
```

У Windows замість `python3` зазвичай можна використати `py -3`. Для іншого розташування даних передайте `--root /шлях/до/репозиторію`.

Валідатор перевіряє:

1. Схему й типи полів кожного запису, непорожні тексти та узгодженість статусів.
2. Рівність кількості англійських та українських сегментів і точне відтворення `raw_source` із джерельних полів.
3. Точне збереження китайських посилань та тексту у квадратних дужках **для кожної пари сегментів**, включно з кількістю повторів.
4. Формулу та унікальність ID, порядок і унікальність номерів джерельних рядків.
5. Відповідність CSV до JSON, лічильників та оцінок перевірки до `progress.json`, контрольних сум і розміру джерела.

Код завершення **0** означає, що ці автоматичні перевірки пройдено; **1** — знайдені порушення; **2** — файли або параметри не вдалося прочитати. Відомі помилки не приховуються й не виключаються з перевірки. Після документованого виправлення поточний знімок проходить ці структурні перевірки.

Це структурна перевірка, а не оцінка українського перекладу. Вона порівнює джерельні поля з включеним `raw_source`, але не завантажує й не звіряє повний зовнішній CC-CEDICT. Збережені контрольні суми перевіряють цілісність, а не достовірність походження. Історію мовних виправлень та правильність їхніх значень скрипт не підтверджує.
